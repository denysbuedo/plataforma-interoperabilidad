# API governance

Cada API y evento tendrá propietario funcional, responsable técnico, contrato, versión, consumidores conocidos, scopes, SLO y estado. Estados: DRAFT, DEVELOPMENT, TESTING, ACTIVE, DEPRECATED y RETIRED.

Un contrato pasa a ACTIVE solo después de revisión funcional, seguridad, pruebas de compatibilidad, runbook y observabilidad. La retirada requiere notificación, medición de consumidores y decisión registrada.
