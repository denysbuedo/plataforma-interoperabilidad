# ADR-005: Modelo canónico por dominio

## Context

Las fuentes representan las mismas entidades de formas distintas.

## Decision

Definir modelos mínimos por casos de uso y UUID institucionales con mappings externos.

## Consequences

Cada atributo necesita semántica y autoridad; se evita copiar esquemas completos.

## Alternatives

Modelo empresarial universal y exposición directa de modelos fuente; ambos rechazados.
