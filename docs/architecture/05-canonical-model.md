# Canonical model

El modelo canónico evoluciona por casos de uso y no replica esquemas fuente. Usa UUID institucional y conserva IDs externos mediante mappings únicos por `(source_system, source_entity, source_id)`.

Antes de añadir un atributo se documentan significado, propietario, fuente autorizada, clasificación, validación, frescura y regla de corrección. La plataforma no decide unilateralmente qué valor gana.
