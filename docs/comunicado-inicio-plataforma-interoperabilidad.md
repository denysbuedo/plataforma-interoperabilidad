# Inicio de la Plataforma de Interoperabilidad

**Asunto: Inicio de la Plataforma de Interoperabilidad**

Estimados/as:

Estamos iniciando el desarrollo de una Plataforma de Interoperabilidad para facilitar el intercambio seguro y controlado de información entre los sistemas de nuestra institución.

La iniciativa no busca sustituir los sistemas existentes ni rehacer sus aplicaciones. Cada sistema continuará siendo responsable de sus datos. La plataforma ofrecerá interfaces comunes para que los sistemas autorizados consulten la información que necesiten, respetando los permisos y las reglas definidas por sus responsables.

La integración se realizará de forma gradual, priorizando las API que ya estén disponibles. Cuando un sistema no cuente con una interfaz adecuada, evaluaremos con su equipo una alternativa aprobada y de solo lectura. No se propone habilitar acceso indiscriminado a las bases de datos ni publicar información sin autorización.

Actualmente estamos preparando un piloto con Akademos, en un entorno no productivo y con un conjunto reducido de datos de Posgrado. Esta prueba permitirá validar el método de integración, la seguridad y la gestión de cambios antes de considerar otros sistemas.

Para planificar las próximas etapas, solicitamos a cada equipo identificar:

- El responsable técnico y el responsable funcional de su sistema.
- Las interfaces de consulta existentes y su documentación, si está disponible.
- Qué información podría ser útil compartir y quién autoriza su uso.
- Las restricciones técnicas, de seguridad o de actualización que debamos considerar.

Esta información servirá para construir un inventario y priorizar los casos de uso junto con cada equipo. Por ahora no se solicitan credenciales ni accesos a producción.

Compartiremos los resultados del piloto y los siguientes pasos antes de proponer nuevas integraciones.
